### 此网页的用途

- 小鲸鱼BOT后台展示
- “额度与用量”：今日花费、今日剩余、累计花费、今日调用、今日识图
- “用量趋势”：支持 **7 / 14 / 30 天**切换，显示总调用、日均调用和单日峰值
- 响应式布局，适配电脑和手机
- 拥有从本机面板导出的 **30 天真实脱敏数据**
- 不包含密码、日志、聊天记录、设置或 BOT 控制接口

### 新版更新方式

进入网页看板目录后直接运行：

```bash
node tools/export-data.cjs
```

不再需要手动指定 `--env-file`。脚本现在会：

- 默认定位 `D:\Xiaojingyu-QQbot-main`
- 自动读取新版根目录 `.env` 中的密码和端口
- 通过 `/api/state`、`/api/usage` 获取动态额度及最近 30 天趋势
- 从 `server\data\vision-stats.json` 汇总同期识图数量
- 兼容旧数据目录及未补零的日期格式
- 仅输出公开白名单字段，并采用临时文件原子替换，避免更新失败损坏旧快照

**当前采用静态快照，不是实时连接**；

后期迁移到服务器时，可以直接复用这套页面，只需让服务器定期更新同一个 JSON 文件即可。
