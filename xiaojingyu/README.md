### 此网页的用途

- 小鲸鱼BOT后台展示
- “额度与用量”：今日花费、今日剩余、累计花费、今日调用、今日识图
- “用量趋势”：支持 **7 / 14 / 30 天**切换，显示总调用、日均调用和单日峰值
- 响应式布局，适配电脑和手机
- 已成功从本机面板导出 **30 天真实脱敏数据**
- 已通过脚本语法、公开字段白名单及页面资源访问检查
- 不包含密码、日志、聊天记录、设置或 BOT 控制接口

### 后续更新数据

在看板目录运行：

```bash
node --env-file="D:\Program Files (x86)\Xiaojingyu\.env" tools/export-data.cjs --days 30
```

然后提交并推送更新后的 `data/dashboard.json`。**当前采用静态快照，不是实时连接**；

后期迁移到服务器时，可以直接复用这套页面，只需让服务器定期更新同一个 JSON 文件即可。
